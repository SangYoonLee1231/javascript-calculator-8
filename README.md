## 문제 분석 및 설계

### 기능 분석, 할 일 단위 나누기

- [x] 입출력값을 처리하는 기본 로직 및 함수의 뼈대 구현 + 에러 처리 로직 구현
- [ ] 커스텀 구분자를 추출하는 함수 구현
- [ ] 모든 구분자로 입력 문자열에서 숫자를 추출하는 함수 구현
- [ ] 추출한 숫자를 모두 더하는 함수 구현
- [ ] 로직 테스트 및 버그 수정

#### 추가 구현 가능 사항

- [ ] 에러 로직 세분화 (잘못된 입력, 잘못된 구분자 형식, 계산 실패)

<br/>

### 문제 초기 설계

- 입출력 레이어 및 전체 코드 틀 설계

  - App 클래스는 I/O 오케스트레이션만 담당하고, 실제 계산 로직은 ‘순수 함수’로 분리
  - <a href="https://www.npmjs.com/package/@woowacourse/mission-utils?activeTab=readme">`@woowacourse/mission-utils`의 문서 내용</a>을 바탕으로 입출력 메소드 작성
  - 에러 처리 로직 작성

- 계산 로직을 담당하는 3개의 함수를 설계

  - 커스텀 구분자를 추출하는 함수
  - 모든 구분자로 입력 문자열에서 숫자를 추출하는 함수
  - 추출한 숫자를 모두 더하는 함수

- '커스텀 구분자를 추출하는' 함수 설계

  - 함수 입력값: 사용자 입력 문자열
  - 구분자 배열 생성 - 쉼표(,)와 콜론(:)을 원소로 갖으며, 모든 구분자를 담는 배열
  - 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 모든 문자 찾는 로직 설계 <strong>(🤔 고민 포인트)</strong>
  - 찾은 문자을 구분자 배열에 추가
  - 함수 반환값: 구분자 배열

- '모든 구분자로 입력 문자열에서 숫자를 추출하는' 함수 설계

  - 함수 입력값: 사용자 입력 문자열, 구분자 배열
  - 추출 숫자 배열 생성 - 구분자들에 의해 추출된 숫자를 원소로 갖는 배열, 빈 배열로 초기화
  - 구분자 배열의 각 요소를 바탕으로 입력 문자열 분리 (정규 표현식 or split 메소드 활용)
  - 함수 반환값: 추출한 숫자 배열

- '추출한 숫자를 모두 더하는' 함수 설계

  - 함수 입력값: 추출한 숫자 배열
  - 배열을 순회하며 모든 값을 더하기 (reduce 함수 메소드 활용)
  - 함수 반환값: 추출한 숫자를 모두 더한 값 (문제 결과값)
